Ouvrir l'app

Mettre l'app sur ton écran d'accueil (iPhone)

  1. Cette page doit être ouverte dans Safari.
  2. Touche le bouton Partager (carré avec une flèche).
  3. Choisis « Sur l'écran d'accueil », puis Ajouter.

Mettre l'app sur ton écran d'accueil (Android)

  1. Cette page doit être ouverte dans Chrome.
  2. Touche le menu ⋮ en haut à droite.
  3. Choisis « Ajouter à l'écran d'accueil », puis Ajouter.

L'app s'ouvre sur claude.ai : connecte-toi une fois avec ton compte dans ce navigateur et reste connecté.
